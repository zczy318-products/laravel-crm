怎么点完整个流程

  1. 打开 Landing，点右上角或 Hero 里的 Sign in。
  2. 登录页直接点 Sign in → 看到校验错误；随便填邮箱和错误密码 → 看到“账号或密码错误”。
  3. 点 Forgot password? → 填邮箱 → Send reset link → 看到“已发送”页 → 回到登录。
  4. 密码填 demo1234（或右下角紫色 ◐ States → Fill demo login）→ 提交中 → 进入 Dashboard（先显示骨架屏，再出数据）。
  5. Dashboard 里：勾选活动前的圆圈完成它（可撤销）；点某个阶段、KPI 或 “Open” → 跳到占位页，说明去向；右下角 ◐ States 切换有数据 / 空状态 / 加载中。

右下角紫色虚线的 “◐ States” 只是评审用的状态切换器，不属于设计。

需要 Andrew 定的事

  1. 品牌名：现在是占位名 “Relay”。定了之后替换 logo 和文案。
  2. “Continue with Google” 要不要做：现在只是画出来的位置。Krayin 自带的 Google 集成用于日历和通讯录同步，没有 Google 登录，要做需要另外开发。
  3. Landing 的定位：现在按对外产品来做。如果 CRM 只给内部用，可以去掉 landing，/ 直接进登录页。
  4. 没有自助注册：Krayin 没有注册功能，所以全站只有 “Sign in”，并提示“找管理员开通账号”。如果要开放试用，需要另做注册和多租户。
  5. 暗色模式：Krayin 本身有暗色模式，但公司 Web 设计模板还没有审定过暗色，这一版只出浅色。

设计依据和偏离

  • 颜色、字号、间距、圆角、按钮、输入框、卡片、标签、toast 和状态都用公司 Web 设计模板 v1 的数值；只有一个强调色（蓝 #1f66e5），字体是系统字体，没有加载网络字体。
  • Dashboard 用模板里的 C 看板页原型：侧栏 264px（可折叠到 72px），顶栏 56px，KPI 卡带口径说明，“胜率”样本不够时显示 “Can't calculate yet”，不显示 0。
  • 图表都是单系列实心蓝（#2563eb），只有“按类型收入”用了第二种颜色（#db2777），色弱检查通过（ΔE 18.7）。图表不加动画，悬停有提示。
  • 偏离 1：模板不管移动端、landing 和登录页。这几处按票的要求做：landing 和登录页更有品牌感，但颜色和字体保持一致。
  • 偏离 2：稿子是手写 CSS，没有加载 Tailwind 和 Preline 的 CDN（不依赖外网，国内也能打开）。数值都可以一一对应到 Tailwind 类名；实现时用 Tailwind + Preline 免费组件，写成 view override，不改 Krayin 核心文件。
