怎么点完整个流程

  1. 打开 Landing，点右上角或 Hero 里的 Sign in。
  2. 登录页直接点 Sign in → 看到校验错误；随便填邮箱和错误密码 → 看到“账号或密码错误”。
  3. 点 Forgot password? → 填邮箱 → Send reset link → 看到“已发送”页 → 回到登录。
  4. 密码填 demo1234（或右下角紫色 ◐ States → Fill demo login）→ 提交中 → 进入 Dashboard（先显示骨架屏，再出数据）。
  5. Dashboard 里：勾选活动前的圆圈完成它（可撤销）；点某个阶段、KPI 或 “Open” → 跳到占位页，说明去向；右下角 ◐ States 切换有数据 / 空状态 / 加载中。

右下角紫色虚线的 “◐ States” 只是评审用的状态切换器，不属于设计。

稿子里的元素结论依据和建议
登录：校验错误、账号密码错误、忘记密码 → 已发送、记住我不用改SessionController 已经接收 remember；找回密码和 60 分钟有效期是 Krayin 自带的。
顶栏：全局搜索、New 快速新建、通知铃铛不用改对应 mega-search、quick-creation、notifications 组件。通知要在设置里打开才显示。
New leads（含环比）、Won 金额（含环比）、按来源和类型的收入、热销产品、头部客户不用改Dashboard 帮助类已有：getTotalLeadsProgress、getTotalWonLeadValueProgress、getLeadsStatsBySources/Types、getTopSellingProducts、getTopPersons。
管道选择、日期范围、导出 PDF不用改现有 dashboard 有 pipeline_id 和起止日期筛选。7 days / 30 days / Quarter 只是起止日期的快捷选项。
Win rate（本期数值）、“11 leads won”前端可算用现有 won / lost over_time 的数量相加即可。
Win rate 的环比 “4 pts”需定现有接口没有上一期的赢单数和丢单数。建议先去掉环比，只显示本期。
Open leads by stage 每阶段的金额、Open pipeline 总金额需定getOpenLeadsByStates 只返回 COUNT，不返回金额。两种做法：(a) 只显示数量，不改后端；(b) 在这个查询里加 SUM(lead_value)，是一处很小的后端改动。建议先用 (a)。
New leads per week（按周的趋势）前端可算现有 getTotalLeadsOverTime 返回按时间分段的数量，前端可以按周汇总。只能落在 Krayin 已有的分段方式上。
Due today & overdue 待办，以及勾选完成前端可算日历接口 activities.get 按起止日期返回 call / meeting / lunch，并带完成标记。“逾期”要把开始日期往前放宽，再在前端过滤未完成的，数据多了会慢。勾选完成用现有的活动更新接口。
Leads to follow up（“N 天没有活动”）需定Krayin 的“停滞线索”（rotten）按创建时间加上管道的 rotten_days 算，不看最后一次活动。线索列表已经支持 rotten_lead 筛选。两种做法：(a) 改用 Krayin 的定义，文案改成 “Past the pipeline's rotten days”，不改后端；(b) 按最后一次活动时间新写查询。建议先用 (a)。
侧栏 Leads 和 Mail 的数字前端可算需要在布局里多做两次计数查询（这是视图层的改动，不加接口）。也可以先不显示数字。
Landing 页（/）需定现在 / 直接跳到 /admin/login。做 landing 要加一条公开路由和一个视图，属于路由层的小改动。如果 CRM 只给内部用，可以不做 landing。
Continue with Google需定Krayin 没有 Google 登录，要做得新增 OAuth 登录。建议实现时先隐藏这个按钮，位置保留。

设计依据和偏离

  • 颜色、字号、间距、圆角、按钮、输入框、卡片、标签、toast 和状态都用公司 Web 设计模板 v1 的数值；只有一个强调色（蓝 #1f66e5），字体是系统字体，没有加载网络字体。
  • Dashboard 用模板里的 C 看板页原型：侧栏 264px（可折叠到 72px），顶栏 56px，KPI 卡带口径说明，“胜率”样本不够时显示 “Can't calculate yet”，不显示 0。
  • 图表都是单系列实心蓝（#2563eb），只有“按类型收入”用了第二种颜色（#db2777），色弱检查通过（ΔE 18.7）。图表不加动画，悬停有提示。
  • 偏离 1：模板不管移动端、landing 和登录页。这几处按票的要求做：landing 和登录页更有品牌感，但颜色和字体保持一致。
  • 偏离 2：稿子是手写 CSS，没有加载 Tailwind 和 Preline 的 CDN（不依赖外网，国内也能打开）。数值都可以一一对应到 Tailwind 类名；实现时用 Tailwind + Preline 免费组件，写成 view override，不改 Krayin 核心文件。
